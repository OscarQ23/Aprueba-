# Notebooks

Solo archivos `.ipynb`. Convención de nombre (Cookiecutter Data Science):

```
<número>-<iniciales>-<descripción>.ipynb
```

Ejemplos: `01-ar-exploracion-inicial.ipynb`, `02-av-linea-base.ipynb`.

La lógica reutilizable no se queda en el notebook: se mueve a `src/` y el notebook la importa.
